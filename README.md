# TouchBarPill

**[Download for Mac](https://github.com/What-did-you-get-done-this-week/TouchBarPill/releases/download/v0.5.7/TouchBarPill-0.5.7.zip)** (0.5.7)

TouchBarPill is a pill that mirrors the Touch Bar when the OLED is dead but input still works.

Unzip the download and open TouchBarPill.app. If macOS blocks it, right-click the app and choose Open, then Open again.

Hover the pill to expand it. Click the mirror the way you would click the real Touch Bar. Scroll on brightness or volume in the mirror. Right or up raises the level. Left or down lowers it.

The left side of the notch is a simple timer for focus, or for how long a task takes. It is experimental, v1.

There is no auto-update yet. Get new builds from [Releases](https://github.com/What-did-you-get-done-this-week/TouchBarPill/releases).

TouchBarPill uses private Apple APIs. A macOS update may break it. This project is not affiliated with Apple.
